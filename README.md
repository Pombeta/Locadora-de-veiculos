# 🚗 Sistema de Simulação de Locadora em Java

Este projeto é uma **simulação simples de locadora de veículos no terminal**, desenvolvida em Java.

O sistema coleta algumas informações do usuário e, com base na **renda informada**, sugere um veículo disponível para locação.

O objetivo do projeto é praticar **lógica de programação, estruturas condicionais e entrada de dados em Java**.

---

# 📋 Funcionalidades

O sistema realiza:

* Cadastro simples do usuário
* Leitura de dados pelo terminal
* Verificação da renda do cliente
* Sugestão automática de veículo
* Exibição das informações do carro sugerido

---

# 🧾 Informações solicitadas ao usuário

Durante a execução do programa, o sistema pede:

* Nome
* Idade
* Renda mensal
* Confirmação para iniciar a simulação

---

# 🛠 Tecnologias utilizadas

* Java
* Scanner (entrada de dados)
* Estruturas condicionais (`if / else`)
* Estrutura de decisão baseada em renda
javac Locadora.java


# 🎯 Objetivo do projeto

Este projeto foi desenvolvido com foco em **praticar lógica de programação em Java**, utilizando entrada de dados do usuário e estruturas condicionais para tomada de decisões.
